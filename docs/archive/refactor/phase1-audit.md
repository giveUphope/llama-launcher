## 1. 当前页面、路由与导航结构

### 1.1 路由表（当前）

| 路径 | 说明 | 对应功能 |
|------|------|----------|
| `/` | 重定向到 `/dashboard` | — |
| `/dashboard` | 仪表盘（状态 + 快速操作 + 最近日志） | 概览 |
| `/models` | 本地模型管理（列表、导入、元数据） | 模型（本地） |
| `/download` | 在线模型下载（搜索、文件选择、任务列表） | 模型（模型库 + 下载） |
| `/params` | 参数设置（basic/advanced/server/presets/bench 5 子标签） | 参数 |
| `/launch` | 控制台（命令预览、输出、控制） | 服务（部分） |
| `/settings` | 应用设置（引擎/模型/网络/外观/语言） | 设置 |
| `/webui` | Web UI 内嵌 iframe | 服务（辅助） |
| `/basic` `/advanced` 等 | 旧路由重定向 | — |

当前侧栏 7 项：仪表盘、模型、下载、参数、控制台、设置、Web UI。

### 1.2 设计稿目标（6 项一级导航）

概览、模型、服务、参数、日志、设置。其中：
- **模型** 二级：本地模型、模型库、下载任务
- **服务** 二级：运行状态、服务配置
- **参数** 二级：参数预设、自定义参数
- **设置** 二级：常规、llama.cpp、外观、高级、关于

### 1.3 现有功能 → 目标页面映射

| 当前功能 | 目标页面 | 处理方式 |
|----------|----------|----------|
| `/dashboard` 仪表盘 | 概览 | 保留并精简（当前已较符合设计：只展示状态+操作+最近日志） |
| `/models` 模型列表 | 模型 → 本地模型 | 保留，增加搜索/筛选、状态术语（可用/缺失/损坏/校验中/不兼容） |
| `/download` 模型搜索 + 文件选择 | 模型 → 模型库 | 移入模型页标签 |
| `/download` 下载任务列表 | 模型 → 下载任务 | 移入模型页标签 |
| `/launch` 控制台 | 服务 → 运行状态 | 重构为运行状态 + 服务配置 |
| `/launch` 命令预览 | 服务 → 服务配置 | 移入服务配置页 |
| `/params` 5 子标签 | 参数 → 预设 + 自定义参数 | 简化为 2 子标签 |
| `/settings` | 设置 → 常规/llama.cpp/外观/高级/关于 | 重分组 |
| `/webui` iframe | 服务页内嵌 | 不作为一级导航 |
| 日志 | 日志 | **缺失**：当前无独立日志中心，需在阶段三新增 |

## 2. Pinia Store 及其负责的数据

| Store | 当前职责 | 状态结构 | 阶段一影响 |
|-------|----------|----------|------------|
| `settings` | 加载/保存设置、切换主题/语言/视觉效果、侧栏折叠、关闭窗口行为 | `AppSettings` | 需增加设计令牌相关设置项 |
| `i18n` | 以 settings.language 为数据源 | — | 无影响 |
| `params` | `values` + `enabled` 双状态、预设、依赖联动、草稿检测 | `PresetValues` | 无影响 |
| `server` | 状态/pid/host/port/url、运行参数快照、输出数组（上限 5000） | `ServerStatus` + `OutputEntry[]` | 无影响 |
| `download` | 任务列表、IPC 监听 | `DownloadTask[]` | 无影响 |

**阶段一不修改任何 Store 状态结构。**

## 3. 渲染进程 → preload → 主进程 IPC 调用链（关键）

| UI 操作 | IPC 通道 | 主进程处理 |
|---------|----------|------------|
| 扫描模型 | `models:scan` | `scanModels` |
| 获取 GGUF 元数据 | `models:getMeta` | `getGgufMeta` |
| 启动服务 | `server:start` | `Launcher.start()` |
| 停止服务 | `server:stop` | `Launcher.stop()` |
| 重启服务 | `server:restart` | `Launcher.restart()` |
| 获取服务器状态 | `server:getStatus` | `Launcher.getStatus()` |
| 预览命令 | `server:previewCommand` | `buildCommand` |
| 下载开始 | `download:start` | `DownloadManager` |
| 暂停/恢复/取消 | `download:pause/resume/cancel` | `DownloadManager` |
| 输出/状态事件 | `server:onOutput/onStatus` | `Launcher` 事件推送 |
| 下载事件 | `download:onProgress/onComplete/onError` | `DownloadManager` |
| 设置保存 | `settings:save` | 文件 IO |
| 预设 | `presets:save/load/list/delete` | 文件 IO |
| 系统 | `system:findLlamaExe`, `window:*`, `clipboard:*` | 系统操作 |

**未发现隐藏或未记录的 IPC 通道。完整清单见 `docs/ipc-channels.md`。**

## 4. 现有业务流程

| 流程 | 现状 | 备注 |
|------|------|------|

## 6. 风险清单

| 风险 | 等级 | 控制方式 |
|------|------|----------|
| 颜色调整影响所有已有组件 | 中 | 统一通过 CSS 变量，改一次 token 全局生效 |

## 8. 未决问题

1. **圆角体系**：设计稿要求小圆角（4–12 px），当前为胶囊化（999 px）。保留当前还是改为设计稿？建议保留胶囊化（用户已确认），设计稿为参考。
2. **毛玻璃效果**：设计稿偏"专业桌面工具"风格，不使用毛玻璃。当前已实现且用户确认。建议保留。
3. **日志中心**：当前无独立日志页面。阶段三需新增，设计稿要求虚拟滚动+筛选+搜索。
4. **6 页 vs 7 页导航**：当前 7 项（含 Web UI），设计稿 6 项。阶段二/四决定 Web UI 是否作为独立一级导航或移入服务页。
